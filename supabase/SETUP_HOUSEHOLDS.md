# เปิดใช้ Dashboard บ้านครอบครัว

1. รอ Vercel deploy commit นี้สำเร็จ (เว็บจะยังใช้หน้าส่วนตัวเดิมจนรัน SQL)
2. Supabase → SQL Editor → New query: คัดลอก **ทั้งไฟล์** `migrations/20260923_households.sql` แล้ว Run
3. ตั้ง Admin คนแรก: ใช้ไฟล์ `bootstrap_admin.sql` เปลี่ยนอีเมลตัวอย่างเป็น **อีเมลที่ใช้เข้าเว็บสาริบุตรจริง** แล้ว Run
4. รีเฟรชเว็บ เปิดบ้านเดิม → แก้ไขบ้าน: ตั้งชื่อ เช่น บ้านครอบครัวลุงสุข กรอกที่อยู่ ผู้ประสานงาน และปักหมุด
5. กด บ้านและตัวฉัน → เลือกบ้าน → ค้นหาชื่อตัวเอง → ส่งคำขอ จากนั้น Admin ตรวจและอนุมัติ (Admin อนุมัติคำขอตนเองได้)
6. บัญชีอื่นเข้าสู่ระบบจะเห็นชื่อ บ้าน และเครือญาติร่วมกัน แต่ไม่เห็นวันเกิดเต็ม เบอร์โทร ที่อยู่ปัจจุบัน ประวัติ ที่อยู่บ้านละเอียด และพิกัดจริงของบ้านอื่น

## การย้ายข้อมูลเดิม

- รหัสบุคคลและความสัมพันธ์เดิมคงอยู่ ไม่ลบหรือรวมคน
- แต่ละเจ้าของข้อมูลเดิมได้บ้านเริ่มต้นหนึ่งบ้าน ชื่อ “บ้านครอบครัวของฉัน” และสิทธิ์สมาชิกบ้านนั้น
- ไม่เดาว่าบุคคลใดเป็นเจ้าของบัญชี ต้องส่งคำขอและให้ Admin ตรวจสอบ
- หากหลายบัญชีมีบุคคลเดียวกันอยู่เดิม จะไม่รวมอัตโนมัติ Admin ต้องตรวจแยกเป็นรายกรณี
- การจัดบ้านจริงจากข้อมูลหลายครอบครัวที่เคยบันทึกรวมกัน: Admin แก้บุคคล เลือกบ้านปลายทาง

## สิทธิ์

- สมาชิกแก้บ้านและสมาชิกบ้านตัวเอง รวมถึงความสัมพันธ์พ่อ แม่ คู่สมรส ลูกภายในบ้าน
- ตัวฉันที่ยืนยันแล้วเชื่อมกับบิดา มารดา และคู่สมรสที่มีในระบบข้ามบ้านได้ ไม่ได้สิทธิ์แก้ข้อมูลบุคคลปลายทาง
- เชื่อมข้ามบ้านแทนคนอื่น เชื่อมพี่น้องโดยตรง ย้ายบุคคล และลบบุคคล: Admin
- พี่น้อง / ลูกพี่ลูกน้องคำนวณจากกราฟที่บันทึกแล้ว การเรียงอายุไม่เผยวันเกิดบ้านอื่นและไม่เดาเมื่อข้อมูลไม่ครบ
- การอนุมัติสมาชิกและตัวบุคคล: Admin เท่านั้น
- ตารางดิบถูกเพิกถอนสิทธิ์ browser; ใช้ RPC ที่ตรวจสิทธิ์และเลือกเฉพาะคอลัมน์ที่เปิดเผย ไม่ใช่ซ่อนข้อมูลด้วย CSS

## แผนที่

Leaflet + OpenStreetMap แสดงพิกัดกลางปัดทศนิยม 2 ตำแหน่ง (โดยประมาณ) พิกัดจริงเฉพาะสมาชิกบ้านและ Admin ในฟอร์มแก้ไขบ้าน ไม่มีการค้นหาที่อยู่ส่งไป geocoder; เลื่อน/ซูมแผนที่แล้วคลิก หรือกรอกละติจูด/ลองจิจูดเอง

## ตรวจสอบ

`npm run build`

ฐานข้อมูลทดสอบแยก ไม่เชื่อมข้อมูลจริง:
`npm install --no-save --package-lock=false @electric-sql/pglite jsdom`
`node tests/households.mjs`
`node tests/dashboard.mjs`

ห้ามลบ RLS หรือเปิด SELECT ทุกคอลัมน์เพื่อแก้ error ให้ตรวจว่ารัน SQL ครบและ deploy รุ่นตรงกัน

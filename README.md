# สายใยครอบครัว — ตระกูลสาริบุตร

Web App สำหรับบันทึกและเชื่อมโยงเครือญาติ แสดงความสัมพันธ์ระหว่างพ่อ แม่ คู่สมรส ลูก พี่น้อง และสมาชิกในสายตระกูล

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

รุ่นเริ่มต้นใช้ข้อมูลตัวอย่างในหน้าเว็บ และพร้อมเชื่อมระบบสมาชิกกับฐานข้อมูลในขั้นต่อไป
